# YouTube Analytics Data Cleaning using SQL

## Overview

This project focuses on cleaning and preparing a raw YouTube analytics dataset using SQL. The dataset contained various data quality issues such as missing values, invalid entries, inconsistent formats, and duplicate records. The goal was to transform the raw data into a clean and structured dataset that can be used for analysis and reporting.

## Problem Statement

Real-world datasets often contain errors and inconsistencies that affect the quality of analysis. In this project, the YouTube analytics dataset included missing values, duplicate records, incorrect data types, inconsistent category names, invalid dates, and unwanted entries. These issues needed to be identified and resolved before the data could be used effectively.

## Dataset Information

The dataset contains information related to YouTube videos, including:

* Video ID
* Channel Name
* Video Title
* Category
* Views
* Likes
* Dislikes
* Comments
* Publish Date
* City
* Status

## Tasks Performed

### Data Exploration

* Examined the dataset to understand its structure.
* Identified missing values across different columns.
* Detected duplicate records.
* Checked for invalid entries and incorrect data formats.

### Data Cleaning

* Handled missing and invalid values.
* Removed records with critical missing information.
* Standardized category names, city names, and status values.
* Converted columns to appropriate data types.
* Corrected date formats.
* Cleaned text fields and removed unnecessary characters.

### Data Validation

* Compared record counts before and after cleaning.
* Verified that important fields contained valid data.
* Ensured consistency across the cleaned dataset.

## SQL Concepts Used

* SELECT
* WHERE
* GROUP BY
* HAVING
* CASE
* UPDATE
* DELETE
* ALTER TABLE
* REGEXP
* Aggregate Functions

## Outcome

After completing the cleaning process, a new table containing clean and consistent records was created. The final dataset is suitable for further analysis, reporting, and dashboard development.
